03 · Admin panel · plan

Change the site from the workshop floor.

A small, phone-first admin for Pratik Davda: update a price, mark a model out of stock, add delivery photos. It's also built as a reusable template, so every Davada-specific part sits in one config file.

01

Same words as the site

Gujarati first, with an English switch. Section names in the admin match the headings on the website, so “સનેડા” here is “સનેડા” there.

02

Save is live, and undoable

No drafts or publish step. Saving updates the site at once, with a 10-second undo, and every change is kept in a history list he can roll back from.

03

Forms, never code

Every field is a plain input, switch, chip or photo picker. No HTML, no markdown, no image sizes to think about: photos are compressed on upload.

04

Built once, reused

Screens are generated from a schema of collections and fields. A new client is a new config file, colours and fonts, not a new admin.

Structure

What he can edit

Two kinds of content. Collections are lists he adds to. Pages are fixed sections with editable text. The bottom tabs on a phone carry the three things he touches most.

Template · reuse

One file per client

To reuse for another business: copy the template, edit this config, swap the brand tokens and logo, deploy. The website reads the same content, so the two never drift apart.

site: {
  name:     { gu: "દવડા ઍગ્રો ઇન્ડસ્ટ્રીઝ", en: "Davada Agro Industries" },
  locales:  ["gu", "hi", "en"],   default: "gu",
  numerals: { gu: "gujr" },        // display only; inputs stay 0–9
  brand:    { primary: "#19203F", accent: "#E07B16", logo: "mark.svg" },
  contact:  { phone, whatsapp }
}

collections: {
  products: {
    label: { gu: "સનેડા" },  sortable: true,  idPattern: "K?-##",
    fields: {
      photos: images(max 6),   name: text.i18n,   desc: longtext.i18n,
      cat:    choice("3", "4", "impl"),
      price:  money(hideable),  stock: toggle,    best: toggle,
      specs:  group(hp, gears, load, tank, start, warranty)
    }
  },
  gallery: { fields: { media: images | youtube, cat: choice(5),
             caption: text.i18n, product: ref(products) } },
  awards:  list(year, icon, title.i18n, by.i18n),
  reviews: list(quote.i18n, name.i18n, village.i18n)
}

pages: { hero, subsidy, stats, contact }
Suggested stack

The site stays a fast static page that reads one content.json. The admin is a small web app on a hosted backend (for example Supabase: database, photo storage, phone-OTP login). No server for him to maintain.

Access

Login with mobile number + OTP. Only numbers on an allow-list can sign in. One role (owner) for now; the schema leaves room for a limited staff role later.

Safety nets

10-second undo after every save. History keeps 30 days of changes and deleted items. A nightly export of content.json as a backup.

Admin language

All admin labels live in one strings file (gu + en). The Gujarati labels on these boards are drafts for Pratik to review.
